## KaiOS Zapp Research

Investigação técnica independente sobre o **Multilaser Zapp II**, sua
plataforma embarcada, hardware, firmware, sistema operacional e
ambiente de software.

O projeto reúne experimentação prática, análise de sistemas,
engenharia reversa, desenvolvimento, documentação técnica e
investigação sobre o KaiOS 2.5.

---

## Sobre o projeto

O projeto nasceu de uma investigação prática sobre um dispositivo
KaiOS 2.5, envolvendo diferentes camadas da plataforma:

```text
Hardware
   ↓
SoC / ARM / MT6572
   ↓
Firmware
   ↓
Android / Linux
   ↓
Gonk
   ↓
Gecko / B2G
   ↓
KaiOS
   ↓
Webapps / WebAPIs
