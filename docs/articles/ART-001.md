    <title>WebIDE, depuração remota e investigação de APIs no KaiOS 2.5</title>
    <sect2>
      <title>1. Visão geral</title>
      <para>O WebIDE é uma ferramenta de desenvolvimento baseada nas ferramentas de desenvolvedor do Firefox usada para conectar um computador a dispositivos baseados em Gecko/B2G, incluindo aparelhos com KaiOS 2.5.</para>
      <para>No contexto do KaiOS 2.5, ele pode ser utilizado para:</para>
      <orderedlist>
        <listitem>
          <para>conectar-se ao runtime do aparelho; </para>
        </listitem>
        <listitem>
          <para>instalar e executar aplicações; </para>
        </listitem>
        <listitem>
          <para>abrir as ferramentas de desenvolvimento; </para>
        </listitem>
        <listitem>
          <para>visualizar logs; </para>
        </listitem>
        <listitem>
          <para>executar JavaScript no contexto da aplicação; </para>
        </listitem>
        <listitem>
          <para>inspecionar HTML e CSS; </para>
        </listitem>
        <listitem>
          <para>depurar código JavaScript; </para>
        </listitem>
        <listitem>
          <para>investigar APIs WebAPI expostas pelo runtime; </para>
        </listitem>
        <listitem>
          <para>estudar diferenças entre o ambiente normal de uma aplicação e ambientes privilegiados. </para>
        </listitem>
      </orderedlist>
      <para>A documentação oficial do KaiOS para o ambiente 2.x recomenda especificamente o Firefox 59 para o fluxo tradicional de desenvolvimento com WebIDE e descreve a conexão através de ADB e do debugger-socket. </para>
      <para>Este capítulo é particularmente relevante para engenharia reversa e experimentação em aparelhos KaiOS 2.5 com acesso ADB/root, inclusive para investigar projetos antigos como o strukturart/shell-command.</para>
      <para>Há, entretanto, uma distinção importante:</para>
      <para>ADB, root e WebIDE são mecanismos diferentes. Ter acesso root ao shell não significa automaticamente que uma aplicação KaiOS possa executar comandos de shell.</para>
      <para>O objetivo do WebIDE, neste contexto, é justamente permitir investigar o que o runtime JavaScript do aparelho ainda expõe.</para>
      <para/>
    </sect2>
